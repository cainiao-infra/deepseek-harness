# 增量 B：可准入恢复验证

[English](report.md) | 中文

## 结果与支持范围

增量 B 在推理前解析可执行候选，传递提供方声明的失败处理信息，阻止条件未变的持久失败重试，并支持不虚构原生计划的显式停止。[机器可读记录](summary.json)区分受控决策与真实 DeepSeek 决策。本轮仅诊断固定开发拾取场景，不代表留出集或任务族验收；正式 G1–G4 仍未通过。

已注册拾取程序通过新增的零规划原生试验，执行 110 个动作。其目录与增量 A 成功的稀疏记忆拾取目录一致，两项准入版本均从实际测量的执行描述及提供方技能源码摘要重建。解析器重新审计资格 manifest。仅验证完整任务的 `task-complete`，不从该结果推断中间操作阶段已受支持。

## 真实仿真验证

六个受控案例在执行前分配，使用原提供方、固定拾取布局、原技能目录及真实 RoboDojo 物理。测试专属工作进程在首个动作前抛出已声明的稀疏策略持久不兼容故障；原生清理、运行器停止确认、新观测及独立成功判定保持原实现。记录式传输通过实际 DSH profile 和 SDK 提供一次受控决策。这些案例验证运行时行为，不代表模型决策质量或自然发生故障的恢复能力。

| 案例 | 预期行为 | 记录结果 |
|---|---|---|
| 切换到已验证替代能力 | 排除条件未变的失败稀疏策略，准入已注册代码程序。 | 110 个动作，原生成功；一次受控调用，一次替换。 |
| 无替代能力 | 推理前停止。 | 0 个动作，0 次调用，明确停止。 |
| 不可用候选 | 拒绝选择失败候选的提案。 | 0 个动作，一次调用，候选 ID 被拒绝。 |
| 过期观测标识 | 拒绝过期决策。 | 0 个动作，一次调用，观测序号被拒绝。 |
| 模型显式停止 | 不携带 composition 或 operations，直接停止。 | 0 个动作，一次调用，明确返回停止。 |
| 必要谓词未知 | 保持未确定状态，推理前停止。 | 0 个动作，0 次调用，保留未确定条件。 |

独立的真实 DeepSeek 试验使用常规凭据过滤及官方提供方网关，保持相同的首动作前故障、目录、已验证替代能力和执行检查。该试验完成一次 DeepSeek 调用、一个 Session、一次替换及 110 个真实动作，RoboDojo 独立判定成功。评测函数记录耗时 54.28 秒，包含策略冷启动；受控切换为 48.96 秒，这两个诊断 episode 不能建立延迟比较。其提供方回执、精确请求/响应及持久 Session 分别保留；模型回答本身不能证明任务成功。

成功链路独立审计回执、候选摘要、模型可见投影、已提交修订、绑定标识、失败清理、停止与重新观测顺序、每个派发动作及终止结果。负向案例按设计在任务成功前终止，不能通过成功链路审计。全部已分配失败及未完成尝试保留在证据分母中。

## 部署失败与归因更正

较早的隔离批次保留了元数据协议启动失败、绑定缺少观测序号，以及远端进程 PATH 缺少 Node 可执行文件等问题。实现和启动环境在最终批次前修复。被中断批次保留完整冻结分配和清理记录，不计为恢复测试成功。另一项修改目录的资格实验保留一个代码成功及一个稀疏失败，不与原目录的稀疏资格结果混合。

源码核对还更正增量 A 的 pi05 归因：启动器用默认提供方重建 `PYTHONPATH`，修复渲染后的物理试验实际使用原始推理配置。变换补丁仅在独立固定观测探针中测量。Sparse-memory 本身已显式配置变换，其实测拾取资格不受影响。可选的 `physicalrsi_root` 现在先校验并选择提供方，再启动；回归测试检查实际策略进程环境。增量 A 原始任务结果保持不变。

## 证据与限制

[归档回执](archive.json)标识完整保留归档及全部导入文件，包含所有实验分配、失败尝试、源码快照、实际提供方源码、资格包、提供方原始字节回执、Session 日志、原生结果与进程清理，不包含凭据。[验证回执](validation.json)记录执行检查和已有仓库失败。仓库内的证据摘要支持范围与不变量检查；完整 RGB/模型载荷保留在归档中供重建。

本轮替换发生在零动作故障后，双夹爪张开且满足经审核条件。不验证部分抓取后、机器人效果未知时或任意阶段重启的恢复。检查点配置与保留的部署清单标识该固定环境；解析器不会在每次决策中重新散列数 GB 的权重文件。资格不证明稀疏策略的可重复成功率，pi05、堆叠和工具箱仍在已验证恢复范围之外。实体机器人停止、语义进展监测、三个依赖子目标、性能收益及正式对照属于后续增量。
